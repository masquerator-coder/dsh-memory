# 项目记忆文件位置

项目的工作记录（派生摘要）固定存放在项目根目录的 `.agents/memory/MEMORY.md`；不要写回仓库根目录的 `DSH_MEMORY.md`。该文件由 dsh-memory 从 L2 工作记录自动派生，可随时重新生成。
